Statistical Formulas

Essential formulas for study and research.

Pearson Product-Moment Correlation

r = [nΣxy − (Σx)(Σy)] / √{[nΣx² − (Σx)²][nΣy² − (Σy)²]}

Spearman Rank Correlation

ρ = 1 − 6Σd² / [n(n²−1)]

Kendall’s Tau

τb = (C−D) / √[(C+D+Tx)(C+D+Ty)]

Goodman–Kruskal’s Gamma

γ = (C−D) / (C+D)

Somers’ D

D(Y|X) = (C−D) / (C+D+Ty)

Point-Biserial Correlation

rpb = [(X̄1−X̄0)/sX]√(pq)

Biserial Correlation

rb = rpb√(pq) / y

Phi Coefficient

φ = (ad−bc) / √[(a+b)(c+d)(a+c)(b+d)]

Polyserial Correlation

rps = Cov(X,Z) / (σXσZ)

Polychoric Correlation

rpc = ρ̂ from the bivariate-normal latent-variable likelihood

Partial Correlation

rXY·Z = (rXY−rXZrYZ) / √[(1−rXZ²)(1−rYZ²)]

Multiple Correlation

R = √(1−SSE/SST)

Canonical Correlation

Rc = corr(U,V)

Kendall’s W

W = 12S / [m²(n³−n)]

Mean

x̄ = Σx / n

Sample Variance

s² = Σ(x−x̄)² / (n−1)

Sample SD

s = √s²

Standard Error

SE(x̄) = s / √n

z-score

z = (x−μ) / σ

Binomial PMF

P(X=x)=C(n,x)pˣ(1−p)ⁿ⁻ˣ

Poisson PMF

P(X=x)=e⁻λ λˣ / x!

Normal PDF

f(x)=1/(σ√2π)e⁻((x−μ)²/2σ²)

Confidence Interval

estimate ± critical × SE
