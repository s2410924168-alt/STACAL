# Statistical Hub — Complete Multi-Page v3

Pages:
- `index.html` — Home: graphic + About
- `tools.html` — Statistical tools
- `distributions.html` — all 40 distributions
- `distribution.html?name=Normal` — individual distribution calculator
- `formulas.html` — formulas
- `about.html` — about
- `style.css`, `script.js` — shared design and calculator engine

The distribution calculator supports PMF/PDF, CDF where numerically practical, theoretical mean/variance, and an interactive canvas graph. Some advanced/multivariate distributions have moments or point calculations that are inherently limited in a one-dimensional calculator; those fields show N/A/Undefined rather than inventing a result.
